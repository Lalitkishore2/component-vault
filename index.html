Hardware Lab FAQ & Operations Guide

Click Assign on any component card or table row. Enter the borrower's name, assign to a project, specify the loan quantity, and set an expected return date. The ledger will automatically deduct the available count and mark overdue returns if not checked back in.

Bins use standard alphanumeric tags such as BIN-MCU-01 or SHELF-PWR-B. Use the search bar or filter drawer to instantly find all items allocated to a specific bin.

Press / or Ctrl+K anywhere to immediately jump to the search box. Press ? to open this Guide. Press Esc to close any dialog or filter popover.

All records are persisted locally in localStorage and synced to your cloud Firebase database. You can also export a downloadable JSON snapshot anytime using the Backup button.
